# Problema detectado

## Problema principal
La carga de evidencia multimedia en el proceso de entrega y recepción de equipos requiere demasiados pasos manuales y no siempre se cumple correctamente.

## Causas identificadas
- No existe conexión directa entre dispositivos móviles y el ERP.
- Las fotografías deben cargarse primero en una carpeta del servidor de archivos.
- Posteriormente deben subirse manualmente como recursos al comprobante del ERP.
- El usuario depende de acceso al servidor de base de datos o servidor de archivos.
- El proceso no obliga de forma simple y móvil a capturar checklist y evidencia en el mismo punto operativo.

## Impactos
- Evidencias incompletas o no cargadas.
- Mayor tiempo operativo para bodega.
- Dificultad para localizar historial multimedia.
- Dependencia de pasos que pueden ser omitidos.
- Riesgo de falta de respaldo ante consultas de cartera o cobro.

## Enfoque correcto del problema
El problema no es únicamente almacenamiento de fotos. El problema es falta de trazabilidad simple y móvil entre contrato, equipo, movimiento, checklist, usuario responsable y evidencia multimedia.
