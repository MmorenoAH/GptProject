# Proceso actual

## Descripción general
El proceso actual se apoya en el ERP para trazar los movimientos de artículos asociados a contratos. La estructura operativa parte del contrato y contiene comprobantes o movimientos como remitos, cambios de mercadería y devoluciones.

## Flujo actual de bodega
1. El usuario de bodega entrega o recibe un equipo.
2. Toma fotografías del estado físico del equipo.
3. Llena un formulario/checklist generado manualmente por el sistema.
4. Guarda las fotografías en una carpeta del servidor de archivos.
5. Ingresa al ERP.
6. Localiza el remito o comprobante correspondiente.
7. Sube manualmente las fotografías al módulo de recursos del comprobante.

## Flujo actual de consulta por cartera
1. Cartera accede al contrato en el ERP.
2. Revisa los comprobantes generados dentro del contrato.
3. Abre el comprobante específico.
4. Consulta el módulo de recursos para revisar la evidencia multimedia.

## Estructura de referencia en ERP
- Contrato
  - Remito
  - Cambio de mercadería
  - Cambio de mercadería
  - Devolución

## Dolor operativo
El proceso exige demasiados pasos manuales y depende de conexión con el servidor de archivos y con el ERP. Esto provoca riesgo de omisiones, demoras y dificultad para consultar historial de evidencias.
