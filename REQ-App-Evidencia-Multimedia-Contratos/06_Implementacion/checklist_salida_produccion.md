# Checklist de salida a producción

## Configuración
- [ ] Formulario Zoho Forms creado.
- [ ] Campos obligatorios configurados.
- [ ] Reglas dinámicas configuradas.
- [ ] Integración con Zoho CRM validada.
- [ ] Almacenamiento en Google Drive configurado.
- [ ] Permisos de Drive revisados.

## Datos
- [ ] Contratos disponibles para consulta.
- [ ] Equipos disponibles para consulta.
- [ ] Relación contrato-equipo validada.
- [ ] Tipos de movimiento definidos.

## Seguridad
- [ ] Rol Super Admin configurado.
- [ ] Rol Bodega configurado.
- [ ] Rol Cartera configurado.
- [ ] Cartera sin permisos de edición sobre evidencia.
- [ ] Prueba de acceso por rol ejecutada.

## Pruebas
- [ ] Prueba de entrega ejecutada.
- [ ] Prueba de recepción ejecutada.
- [ ] Prueba de consulta de historial ejecutada.
- [ ] Prueba de evidencia incompleta ejecutada.
- [ ] Prueba con contrato sin equipos ejecutada.

## Capacitación
- [ ] Bodega capacitada en captura móvil.
- [ ] Cartera capacitada en consulta.
- [ ] Administrador capacitado en mantenimiento.

## Go-live
- [ ] Aprobación funcional recibida.
- [ ] Aprobación técnica recibida.
- [ ] Fecha de salida definida.
- [ ] Canal de soporte inicial definido.
